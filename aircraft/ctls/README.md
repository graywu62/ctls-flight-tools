# CTLS Flight Tools

面向CTLS的纯前端飞行准备工具。V3.0包含载重平衡、燃油计划、起飞/着陆性能及电子检查单四个独立模块。

电子检查单的飞行前检查和正常程序完全按《飞行检查单A5（定稿）》录入；应急程序保持《AF 0430 0003》Rev.24 CH0版本。适用于AeroJones CTLS / ROTAX 912 ULS化油器构型，不得用于替代批准的飞行手册、补充文件或纸质检查单。

## 运行与安装

推荐通过 HTTPS 静态网站或本地服务器运行：

```powershell
python -m http.server 8080
```

访问 `http://localhost:8080/`。首次成功加载后，支持浏览器安装及离线访问。直接双击 HTML 可以计算，但 `file://` 模式不支持 PWA 离线安装。

## 受控航空数据

- 适用产品：AeroJones CTLS，MTOW/MLW 600 kg。
- 可用燃油：126 L；总容量 130 L。
- AVGAS 100LL 换算密度：0.72 kg/L（15 °C 基准）。
- 燃油巡航性能参考范围：3,000–9,000 ft。
- 起飞/着陆性能表范围：400–600 kg、密度高度 0–8,000 ft。

数据来源应在每次商业发布前由授权飞行运行或适航人员对照适用飞机的最新 POH、补充文件和设备构型复核。软件结果不能替代批准的 POH、飞行员判断或运行放行程序。

## 数据与隐私

所有输入和自定义飞机资料仅保存在当前浏览器的 `localStorage`，不会上传至服务器。飞行计划数据有效期为 48 小时。清除浏览器站点数据会删除本地资料。

## 测试

```powershell
node tests/run-tests.js
```

发布前还应完成：桌面/手机浏览器检查、三个工具往返数据检查、离线启动检查，以及 A4 打印检查（起飞/着陆性能固定两页）。

## 部署

`deploy/deploy-to-cos.ps1` 从环境变量读取腾讯云凭据，不会上传测试目录、原始摄影文件或下划线开头的开发文件。生产环境必须启用 HTTPS，并保留上一版本以便回滚。
