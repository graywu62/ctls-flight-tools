# CTLS Flight Tools 回归测试

测试仅使用 Node.js 内置模块，不需要安装第三方依赖，也不会访问网络。

在项目根目录运行：

```powershell
node tests/run-tests.js
```

当前覆盖：

- 正常起飞和着陆计算
- 低于 POH 性能表最低重量
- 超出 POH 密度高度范围
- 空白关键输入
- 未提供燃油计划时的着陆状态
- 有效燃油计划下的预计着陆重心
- 计划耗油超过机上燃油
- 燃油密度、可用油量和标准燃油计算
- 巡航性能精确点、插值点和超范围高度
- 工具输入草稿的保存与恢复

新增或修订 POH 数据时，应同步补充对应的已知数据点和边界测试。
